strategy-generator が使用。Executive Nerve Performance の市場上の立ち位置を定義する。

## 1. ポジショニング・ステートメント

```
【誰に】（ターゲット顧客を一文で）
【何を】（提供価値を一文で）
【なぜ我々か】（差別化の核を一文で）

──統合した一文──
「______な経営者に、______を提供する。なぜなら______だから。」
```

---

## 2. 2軸マップ

市場を2つの軸で切り、競合・類似発信者と自社の位置をプロットする。

```
推奨する軸の候補（依頼に応じて選択）:
- 縦軸: 「対症的（不調を取る）」⇔「最適化的（状態を設計する）」
- 横軸: 「経験・感覚ベース」⇔「エビデンスベース」
（他の軸案: 「一般向け⇔経営者特化」「治療⇔パフォーマンス」）

■ 採用した縦軸:
■ 採用した横軸:

           最適化的
              │
   A社 ●      │      ★ENP（狙う位置）
              │
経験ベース ────┼──── エビデンスベース
              │
        B社 ● │  ● C社
              │
           対症的

■ プロット説明:
- ★ENP: なぜこの位置を狙うか
- 各競合の位置と、その根拠
```
