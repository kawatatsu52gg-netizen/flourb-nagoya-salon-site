# テンプレート: YouTube企画書・台本

content-generator が使用。`guidelines/content-rules.md` §3 に従う。

---

## パート1: 企画書

```
■ 動画タイトル案（3案・煽らない／対象と便益が明確）:
  1.
  2.
  3.
■ カテゴリ: 解説系（8-15分） / 深掘り系（15-25分）
■ ターゲット: この動画を見る経営者の状況・課題
■ 1テーマ: この動画で扱う唯一のテーマ（一文）
■ 視聴後の変化: 見終わった経営者に何が起きてほしいか
■ サムネ方向性: 知的に見える設計（煽り禁止）。テキスト案＋ビジュアル方針
■ 出典メモ（科学的主張・確実度ラベル付き）:
```

---

## パート2: 台本

### ① フック（〜30秒）
```
（経営者の課題を30秒で言語化。「これは自分の話だ」と思わせる。
 自己紹介や前置きは最小限。本題から入る）
```

### ② 本編
```
◇ 課題の構造（なぜそれが起きるのか）
   - 自律神経／神経科学の視点で説明
   - 専門用語はテロップ＋一言の言い換えセットで

◇ 根拠（研究では）
   - 「〜という報告がある」と出典感を持って
   - 確実度ラベルに応じた慎重表現（🟡なら「示唆されている」）

◇ 臨床の視点（臨床で見てきたのは）
   - 川辺達也の経験を、断定せず傾向として

◇ 具体策
   - 経営者が今日から試せる、現実的な打ち手
   - 「忙しくてもできる」設計
```

### ③ まとめ（〜1分）
```
（本編の1テーマを一文で再提示。人生スケールの視点で締める）
```

### ④ CTA（穏やかに）
```
（チャンネル登録／Newsletter案内まで。商品の押し売りはしない。
 「今すぐ」「限定」は使わない）
```

### ⑤ 注意書き（必要に応じて）
```
※個人差があります／医療機関の受診を妨げるものではありません 等
```
