# テンプレート: Newsletter原稿

content-generator が使用。`guidelines/content-rules.md` §4 に従う。
**一人の経営者に手紙を書くトーンで。「皆さん」ではなく「あなた」。**

---

## 記入フォーマット

```
■ 号数・配信予定:
■ 件名案（3案・開封したくなる／煽らない）:
  1.
  2.
  3.
■ 1テーマ: この号で扱う唯一の深いテーマ（一文）
■ ターゲットの状態: この号を読む経営者の今の状況
■ 読了時間目安: 7-10分
■ 出典メモ（確実度ラベル付き）:
```

---

## 本文構成

### ① 書き出し（近況・問いかけ）
```
（季節・時事・川辺達也自身の最近の気づきなどから自然に入る。
 読み手に「自分に宛てた手紙だ」と感じさせる導入）
```

### ② 本編（今号のテーマ）
```
◇ 問題提起 — 経営者が抱えがちな課題を具体的に言語化
◇ 科学の視点 — 自律神経・神経科学の知見（出典感を持って・平易に）
◇ 臨床の視点 — 川辺達也が現場で見てきた傾向
◇ 経営者文脈への翻訳 — それが意思決定・事業にどう効くか
◇ （海外トレンド回の場合）Executive Health の最新トピックの紹介と日本文脈での解釈
```

### ③ 今週の小さな実験
```
（読者が今週試せる、無理のない1つの実験を提案。
 「やってみてどうだったか、よければ返信で教えてください」と双方向に）
```

### ④ 次回予告
```
（次号のテーマを一言。続きを読みたくさせる）
```

### ⑤ 署名・注意書き
```
川辺達也
※体調には個人差があります／医療機関の受診を妨げるものではありません
（CTAは控えめに。将来の講座・コミュニティは「予告」程度に留める）
```
