# テンプレート: X投稿案（経営者向け）

content-generator が使用。`guidelines/content-rules.md` §2 に従う。

---

## 記入フォーマット

```
■ 投稿タイトル（管理用・公開しない）:
■ カテゴリ: 気づき系 / 解説系 / 視点系 / 舞台裏系
■ 形式: 単発 / スレッド（◯ポスト）
■ ターゲットの状態: この投稿を読む経営者は今どんな状況・気分か
■ 1メッセージ: この投稿で伝えたい唯一のこと（一文）
■ 想定する読後の変化: 読んだ経営者に何が起きてほしいか
```

### 本文

**【単発の場合】**
```
（フック：1行目で「これ自分のことだ」を作る）

（本文：神経・科学のミニ解説 or 視点の提示。専門用語は訳す）

（着地：明日からの小さな一歩 or 問いかけ）
```

**【スレッドの場合】**
```
1/ フック — 経営者が見落としがちな事実を提示
2/ なぜそうなるか — 自律神経・神経科学の視点（平易に）
3/ 臨床での観察 — 「臨床で多く見てきたのは〜という傾向」
4/ 具体策 — 今日から試せる小さな一歩
5/ 着地 — 人生スケールの視点で締める／穏やかな問いかけ
```

```
■ ハッシュタグ（最大2個）:
■ 出典メモ（科学的主張がある場合・確実度ラベル付き）:
■ 自己チェック（生成エージェントが記入）:
  - [ ] 1メッセージか
  - [ ] content-rules §1（健康表現）違反なし
  - [ ] 根拠×臨床のバランス
  - [ ] 経営者の言語に翻訳済み
  - [ ] 押し売り・煽りなし
  - [ ] 人生スケールの視点あり
  - [ ] フックが刺さるか
```

## 記入例

```
■ 投稿タイトル（管理用）: 午後の意思決定の質
■ カテゴリ: 気づき系
■ 形式: 単発
■ ターゲットの状態: 午後の会議で頭が回らないと薄々感じている経営者
■ 1メッセージ: 午後の判断力低下は「気合い不足」ではなく自律神経の問題
■ 想定する読後の変化: 自分を責めるのをやめ、コンディションの問題として捉え直す

本文:
午後3時の重要な意思決定で、なぜか頭が回らない。
それを「気合いが足りない」と片づけている経営者は多い。

実際は、午前中の緊張モード（交感神経優位）を切り替えられないまま
夕方まで走り続け、回復のタイミングを失っているケースが少なくありません。

意思決定の質は、意志ではなく神経の状態に左右されます。
昼に5分、意図的に呼吸を緩める時間を「会議」として予定に入れてみる。
それだけで午後の景色が変わることがあります。

※体調には個人差があります。不調が続く場合は医療機関の受診を。

■ ハッシュタグ: #経営者の健康
■ 出典メモ: 自律神経の日内変動・回復に関する一般知見（🟢確立）
```
